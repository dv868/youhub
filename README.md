# YOUHUB — HUB 渠道观察站

轻量、只读的 [HUB](https://hub.linux.do)（AxonHub）渠道观察页。自动巡检新上架渠道，**只展示当前仍可用的渠道**（下架 / 停用会自动剔除），并附维护者真实调用测速，帮助按价格与质量快速筛选模型渠道。

**在线访问**：<https://youhub.earbowe.com>

> 新手第一个项目，欢迎提 Issue / PR，也欢迎大佬轻拍。

## 功能

- **只展示活渠道**：每天 3 次自动巡检 + 全量体检，确认下架 / 删除的渠道自动从页面移除（归档到 `dead_channels.json`）
- **渠道列表**：cid、名称、类型、上架时间，自检分数、核验人数、官方渠道、检测报告、降价幅度、预算消耗等徽章
- **筛选与排序**：模型名模糊筛选、类型筛选、渠道名搜索，按最新 / 自检分 / 检测报告 / 官方 / 免费优先排序
- **价格对比**：倍率 / 单价；未标价模型显示「免费」（渠道主申报口径，请自行实测确认）
- **维护者实测**：部分模型带 `⚡ xx tok/s` 徽章——真实调用实测的结果，含测试时间
- **纯只读**：页面没有任何写操作，不收集访客任何数据；「复制」按钮把 cid 复制到剪贴板，回 HUB 即可绑定

## 关于测速数据

页面上的 ⚡ 徽章来自**维护者**对渠道的真实调用实测（速度 + 测试时间），只代表测试时点，仅供参考。

本项目**刻意没有做访客测速 / 众包测速**：HUB 的 key 走动态路由，无法指定渠道，第三方在自己 key 下测出的结果对别人没有参考意义，容易误导。想确认渠道速度，建议绑定后自己小批量试。

## 数据来源

- `incr-data.json`：由维护者的 HUB 增量巡检日志自动生成（每天 3 次），收录 cid 20000+ 的新渠道，并对全部已收录渠道做存活体检
- `speed-tests.json`：维护者实测数据快照
- `dead_channels.json`：确认下架的渠道黑名单，不出现在页面

仓库里的数据快照代表最后一次发布时点；最新数据以在线站页面顶部「数据更新」时间为准。

## 快速开始

```bash
# 纯 Python 标准库，无任何依赖
python3 server.py 8765
# 浏览器打开 http://127.0.0.1:8765
```

环境变量：`BIND`（默认 127.0.0.1）、`DATA_DIR`（默认脚本所在目录）。

开源版 `server.py` 只提供静态服务：`/api/readonly` 恒返回只读（内网管理按钮不会出现），刷新 / 更新等写接口一律 403。代码里另保留一个匿名测速聚合端点，当前前端未使用，留给自部署者参考。

## 部署到 Cloudflare Workers（可选）

在线站即此方式部署，仓库内含 `wrangler.jsonc`：

```bash
npm install -g wrangler
wrangler login
wrangler deploy
```

- 静态资源只从 `public/` 白名单目录发布（不含源码与数据外的任何文件）
- `public/_headers` 已配置 HTML / 数据 `no-cache` 与基础安全头
- Workers 上只跑纯静态页面，没有任何后端 API

## 与在线站的关系

在线站 <https://youhub.earbowe.com> 部署的就是本仓库 `public/` 里的静态文件，由巡检流程在有新渠道时自动发布。渠道采集 / 体检 / 实测依赖维护者私有的 HUB 管理端凭证与脚本，不在本仓库内。
